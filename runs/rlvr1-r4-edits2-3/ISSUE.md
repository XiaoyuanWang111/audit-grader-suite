## Contract changes (after the v1 hash)

- 09:45 UTC. `keywords:palindrome`: a phrase palindrome needs at least 7
  letters across 2 to 10 whole words. Reason: implementing "a phrase of whole
  words that reads the same backwards" needs a minimum; shorter cross-word
  coincidences ("no on") are not something a reader would call an included
  palindrome. Single words keep D-palindrome-length (3).
- 09:45 UTC. New decision `D-start-end-single`: does a one-word response
  "start and end with the same word"? Proposed: yes. Reason: found while
  implementing the contract; the text allows both.
- 09:45 UTC. `D-empty-each` also covers `detectable_format:square_brackets`
  ("every word"), `bigram_wrapping` ("every word bigram") and
  `sentence_hyphens` ("all sentences"): a response with no word or sentence
  fails. Reason: the same question as for "each sentence".
- 09:45 UTC. G2: a number with an internal `.` or `,` between digits (`3.14`,
  `1,000`) is one word. Reason: implementation detail the v1 text left out.

## Findings (details, counterexamples and commands in audit/AUDIT.md section 4)

Pipeline, data, protocol:
- G1 extraction drops a non-reasoning answer containing `<think>` (e.g. `<<think>>`): both graders.
- G2 unclosed reasoning graded as the answer (139 of 1,500 thinking responses): both graders.
- G3 last_word_answer raises IndexError on empty text -> SkyRL INFRA_ERROR, reward 0.
- G4 77 rows with nth_paragraph > num_paragraphs: contradictory text, random SkyRL verdicts.
- G5 147 rows show the marker `P.S` while both graders require `P.S.`.
- G6 word_count_different_numbers: 526 rows grade a relation the text never states.
- G7 unpinned/unverified: run-time punkt_tab download, RL generation settings, route
  `skyrl_gym` vs the session's `task_session` requirement, `verifyit_enabled`.
- G8 rows no response can pass (lowercase/capital + end phrase: 48 + 45; G4's 77).
- G9 content-free: empty text gets SkyRL reward 1.0 on 14.4% of rows.
SkyRL (NVIDIA checkers; same in the reference): S1 to S22.
Task-curation gate (verifyit): T1 to T19.
